# ajs-toolchain (expr-cgen)

A C++ project that converts simple arithmetic expressions into C code using **ANTLR 4**.

The project reads a text file containing mathematical expressions, analyzes them, and generates a C source file (`out.c`) that can be compiled and executed.

---

## How It Works

The project has three main steps:

1. **Reading and Parsing Expressions**
   - Reads expressions from a text file.
   - Uses ANTLR 4 and the grammar defined in `Expr.g4` to understand the input.
   - Creates an Abstract Syntax Tree (AST) containing variables, numbers, operators, and assignments.

2. **Processing the AST**
   - Uses a custom visitor called `CGenExprVisitor` to go through the AST.
   - Finds all variable names and stores each one only once using `std::set<std::string>`.
   - Initializes all variables with the value `0`.
   - Converts each expression into C code and adds `printf` statements to display the results.

3. **Generating C Code**
   - Creates a complete C program.
   - Saves the generated code into `out.c`.

## Project Structure

```text
ajs-toolchain/
├── bin/
│   ├── antlr-4.13.2-complete.jar
│   └── paran-to-tree.html
├── expr/
│   ├── generated/
│   ├── CMakeLists.txt
│   ├── Expr.g4
│   ├── main.cpp
│   └── test1.txt
├── libs/
│   └── antlr4-cpp-runtime/
└── .gitignore
```

- `Expr.g4` – defines the rules for the expression language.
- `generated/` – contains the files generated by ANTLR.
- `main.cpp` – contains the main program and the visitor used to generate C code.
- `test1.txt` – contains example expressions.
- `bin/` – contains the ANTLR tool and an AST visualization tool.
- `libs/` – contains the ANTLR C++ runtime library.

## Requirements

To build and run this project, you need:

- **C++ Compiler:** Supporting C++17 or newer (MSVC, GCC, or Clang).
- **CMake:** Version 3.16 or newer.
- **Java:** JRE/JDK 11 or newer, only if you want to modify the grammar and generate new ANTLR files.

## Build and Run

### 1. Build the Project

Open a terminal in the project folder and run:

```bash
cmake -S expr -B build
cmake --build build --config Debug
```

### 2. Run the Program

Pass the input file as an argument.

**Windows:**

```powershell
.\build\Debug\expr.exe expr/test1.txt
```

**Linux:**

```bash
./build/expr expr/test1.txt
```

### 3. Generated C Code

After running the program, the generated C code is saved in `out.c`.

For example, given the input expressions, the output may look like this:

```c
#include <stdio.h>

int main() {
    int n = 0;
    int x = 0;

    printf("%d\n", (n = (5 + x)));
    printf("%d\n", (n = (40 + (n * 7))));
    printf("%d\n", (((1 + n) / 2)));

    return 0;
}
```

### 4. Compile and Run the Generated Code

You can compile the generated C file using GCC:

```bash
gcc out.c -o out
./out
```
